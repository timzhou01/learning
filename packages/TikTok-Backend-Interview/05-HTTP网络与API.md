## 01. GET、POST、PUT、PATCH、DELETE 的语义？

**参考答案：** GET 读取，POST 提交/创建，PUT 完整替换，PATCH 部分修改，DELETE 删除；幂等是语义与业务实现共同决定的。

## 02. 什么是 HTTP 幂等性？

**参考答案：** 同一请求执行多次与执行一次，对预期服务端状态的效果一致；不代表响应每次相同。

**常见追问：** 扣款请求怎样做到幂等？

**参考答案：** 200 成功，201 创建，202 已接受异步处理，400 参数错误，401 未认证，403 无权限，404 不存在，409 冲突，429 限流，5xx 服务错误。

## 04. HTTPS 如何保障安全？

**参考答案：** TLS 利用证书验证服务器身份，协商会话密钥，随后加密并完整性保护数据；不意味着服务端逻辑无漏洞。

## 05. TCP 三次握手解决什么？

**参考答案：** 协商初始序列号并确认双方发送/接收路径可用，为可靠传输建立连接状态。

**常见追问：** 为什么不是两次？

## 06. TCP 与 UDP 如何选择？

**参考答案：** TCP 提供有序可靠字节流及拥塞控制；UDP 只提供数据报，适合应用自行控制可靠性/时延的场景。

**常见追问：** QUIC 使用什么传输层？

## 07. HTTP/1.1、2、3 有何区别？

**参考答案：** HTTP/2 在单连接复用二进制流但仍受 TCP 队头阻塞；HTTP/3 基于 QUIC，改善传输层多路复用。

**常见追问：** HTTP/2 是否完全没有队头阻塞？

## 08. Cookie、Session、JWT 区别？

**参考答案：** Cookie 是客户端存储/传输机制；Session 通常由服务器维护状态；JWT 是签名声明载体，需考虑过期、吊销和密钥管理。

**常见追问：** JWT 如何主动注销？

## 09. 认证和授权区别？

**参考答案：** 认证回答你是谁；授权回答你能访问哪些资源。授权必须由服务端核验对象和操作权限。

**常见追问：** 什么是越权访问？

## 10. 什么是 CORS？

**参考答案：** 浏览器基于同源策略的跨源访问控制，预检决定某些请求是否被允许；不是服务端安全边界。

**常见追问：** 后端直连接口受 CORS 保护吗？

## 11. CSRF 与 XSS 区别？

**参考答案：** CSRF 利用自动携带凭证诱导跨站请求；XSS 注入恶意脚本；可结合 SameSite、CSRF token、输出编码/CSP 等防护。

**常见追问：** HttpOnly 防止所有 XSS 吗？

## 12. WebSocket 与 SSE 如何选择？

**参考答案：** WebSocket 双向实时通信；SSE 服务器到浏览器单向流式更新，基于 HTTP，适合通知/AI 流式输出。

**常见追问：** 断线重连如何处理？

## 13. 超时和重试怎样配合？

**参考答案：** 设置整体 deadline 和单次超时，按错误性质有限重试、退避加抖动，避免放大流量；非幂等操作须先保障幂等。
