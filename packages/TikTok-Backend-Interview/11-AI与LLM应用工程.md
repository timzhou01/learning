## 01. RAG 是什么？

**参考答案：** Retrieval-Augmented Generation：先检索可信相关材料，再与问题一起送给 LLM 生成回答；适合动态/私有知识，不保证绝对正确。

**常见追问：** 为何不把所有文档直接塞上下文？

## 02. RAG 的基本链路？

**参考答案：** 文档清洗/切块→Embedding→向量或混合索引→检索→重排→构造上下文→生成→引用与评估。

**常见追问：** 如何选 chunk 大小？

- [ ] 已掌握

## 03. Embedding 是什么？

**参考答案：** 将文本映射成向量，使语义相近内容更易被相似度检索找到；版本更新通常需要索引兼容或重建。

**常见追问：** 余弦相似度为何常见？

- [ ] 已掌握

## 04. 向量数据库与普通数据库区别？

**参考答案：** 向量库侧重近似最近邻索引、相似检索与元数据过滤；普通数据库也可加向量扩展，选型看规模与运维。

**常见追问：** ANN 为什么可能漏召回？

## 05. 向量检索和关键词检索如何取舍？

**参考答案：** 向量擅长语义近似，BM25 等关键词适合专名与精确匹配；混合检索和重排可兼顾。

## 06. 什么是 Rerank？

**参考答案：** 对初步召回候选进行更精细的相关性评分，提高前几条质量，代价是额外延迟和成本。

**常见追问：** 什么时候不值得 rerank？

## 07. RAG 如何避免跨用户数据泄漏？

**参考答案：** 检索前就做租户/文档权限过滤，索引隔离、最小权限、审计；不能只指望 Prompt 告诉模型不要泄漏。

**常见追问：** 权限变更后索引如何更新？

## 08. 什么是 Prompt Injection？

**参考答案：** 不可信文档/网页中包含试图指挥模型的恶意指令；将检索内容视为数据，工具权限隔离并做输出校验。

**常见追问：** 为什么系统提示词也不足够？

## 09. LLM 幻觉怎么缓解？

**参考答案：** 检索可核验来源、引用、回答边界、无法确认时拒答、结构化校验与人工复核；无法彻底消除。

**常见追问：** 如何衡量事实准确率？

## 10. Agent 与普通 Workflow 区别？

**参考答案：** Workflow 流程由程序明确控制；Agent 让模型参与规划/选择工具，灵活但更不确定、成本与安全面更大。
