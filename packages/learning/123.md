### Q016 · 深拷贝（循环引用） [P0]

> 归类：**面经直接出现的题型** · [公开来源/参考](https://www.nowcoder.com/discuss/511225079162818560)

**题目（补全版）**：支持对象、数组、Date、RegExp、Map、Set 与循环引用；函数可原样引用；不要求 DOM、WeakMap 内部状态等特殊内建对象。

```ts
function deepClone<T>(input: T, seen?: WeakMap<object, any>): T
```

**示例 / 验收**：

```text
a.self=a，clone.self === clone 且 clone !== a
```

<details>
<summary>展开参考答案（TypeScript）</summary>

```ts
function deepClone<T>(input: T, seen = new WeakMap<object, any>()): T {
  if (input === null || typeof input !== 'object') return input
  if (seen.has(input)) return seen.get(input)
  if (input instanceof Date) return new Date(input) as T
  if (input instanceof RegExp) return new RegExp(input.source, input.flags) as T
  if (input instanceof Map) {
    const out = new Map(); seen.set(input, out)
    input.forEach((v, k) => out.set(deepClone(k, seen), deepClone(v, seen)))
    return out as T
  }
  if (input instanceof Set) {
    const out = new Set(); seen.set(input, out)
    input.forEach(v => out.add(deepClone(v, seen)))
    return out as T
  }
  const out: any = Array.isArray(input) ? [] : Object.create(Object.getPrototypeOf(input))
  seen.set(input, out)
  for (const key of Reflect.ownKeys(input)) {
    const desc = Object.getOwnPropertyDescriptor(input, key)!
    if ('value' in desc) desc.value = deepClone(desc.value, seen)
    Object.defineProperty(out, key, desc)
  }
  return out
}
```

**注意 / 追问**：此实现不是所有内建对象的通用克隆器；生产环境优先评估 structuredClone 的支持范围。

</details>

### Q024 · 对象深层比较 deepEqual [P1]

> 归类：**面经直接出现的题型** · [公开来源/参考](https://www.nowcoder.com/discuss/792457957991587840)

**题目（补全版）**：比较数组、普通对象的结构和值；不要求 Map/Set、循环对象。区分对象键集合是否一致。

```ts
function deepEqual(a: any, b: any): boolean
```

**示例 / 验收**：

```text
deepEqual({a:[1,2]}, {a:[1,2]}) → true
```

<details>
<summary>展开参考答案（TypeScript）</summary>

```ts
function deepEqual(a: any, b: any): boolean {
  if (Object.is(a, b)) return true
  if (!a || !b || typeof a !== 'object' || typeof b !== 'object') return false
  if (Array.isArray(a) !== Array.isArray(b)) return false
  const ka = Object.keys(a), kb = Object.keys(b)
  if (ka.length !== kb.length) return false
  return ka.every(k => Object.hasOwn(b, k) && deepEqual(a[k], b[k]))
}
```

</details>

### Q025 · 对象 diff [P0]

> 归类：**面经直接出现的题型** · [公开来源/参考](https://www.nowcoder.com/discuss/792457957991587840)

**题目（补全版）**：比较两棵 JSON 对象，只返回变化路径；新增、删除和修改分别记录。按题目自定义输出结构。

```ts
function diff(a: Record<string, any>, b: Record<string, any>): Array<{path: string; before: any; after: any}>
```

**示例 / 验收**：

```text
diff({x:1},{x:2,y:3}) → [{path:"x",before:1,after:2},{path:"y",before:undefined,after:3}]
```

<details>
<summary>展开参考答案（TypeScript）</summary>

```ts
function diff(a: any, b: any) {
  const result: Array<{path: string; before: any; after: any}> = []
  function walk(x: any, y: any, path: string) {
    if (Object.is(x, y)) return
    const plain = (v: any) => v !== null && typeof v === 'object' && !Array.isArray(v)
    if (plain(x) && plain(y)) {
      for (const key of new Set([...Object.keys(x), ...Object.keys(y)])) {
        walk(x[key], y[key], path ? `${path}.${key}` : key)
      }
    } else result.push({path, before: x, after: y})
  }
  walk(a, b, '')
  return result
}
```

**注意 / 追问**：简化题设为 JSON 类对象；缺失属性与值为 undefined 的属性会视为等价，若要区分需 hasOwn。

</details>

### Q026 · 模板字符串插值 [P1]

> 归类：**题库补充 / 高频练习** · [公开来源/参考](https://github.com/yangshun/front-end-interview-handbook)

**题目（补全版）**：替换模板中 {{name}} 与 {{user.age}}；找不到的路径返回空字符串；不允许 eval。

```ts
function render(template: string, data: Record<string, any>): string
```

**示例 / 验收**：

```text
render("Hi {{user.name}}", {user:{name:"Tom"}}) → "Hi Tom"
```

```ts
function render(template: string, data: Record<string, any>) {
  return template.replace(/{{\s*([\w.]+)\s*}}/g, (_, key) => {
    const value = key.split('.').reduce((obj: any, part: string) => obj?.[part], data)
    return value == null ? '' : String(value)
  })
}
```

### Q027 · 数组转树与树转数组 [P0]

> 归类：**题库补充 / 高频练习** · [公开来源/参考](https://github.com/yangshun/front-end-interview-handbook)

**题目（补全版）**：输入 id/parentId 列表；生成 children 树；注意乱序节点与不存在的父节点。反向将树扁平化。

```ts
function listToTree(items: Array<{id:number; parentId:number|null}>): any[]
```

**示例 / 验收**：

```text
[{id:2,parentId:1},{id:1,parentId:null}] → [{id:1,children:[{id:2,children:[]}]}]
```

<details>
<summary>展开参考答案（TypeScript）</summary>

```ts
function listToTree(items: Array<{id:number;parentId:number|null}>) {
  const map = new Map(items.map(x => [x.id, {...x, children: [] as any[]}]))
  const roots: any[] = []
  for (const node of map.values()) {
    const parent = node.parentId == null ? undefined : map.get(node.parentId)
    if (parent) parent.children.push(node)
    else roots.push(node)
  }
  return roots
}
function treeToList(nodes: any[]): any[] {
  return nodes.flatMap(({children, ...rest}) => [rest, ...treeToList(children || [])])
}
```

**注意 / 追问**：假设无环且 id 唯一。

</details>

**示例 / 验收**：

```ts
function groupBy<T>(arr: T[], key: (x:T)=>string) {

  return out
}
```

### Q029 · 版本号比较 [P0]

> 归类：**面经直接出现的题型** · [公开来源/参考](https://www.nowcoder.com/feed/main/detail/bd29ded4f74842edb2291f32efcb3f5f)

**题目（补全版）**：比较点分整数版本号；短版本补 0；不要浮点转换或直接字典序比较。

```ts
function compareVersion(a: string, b: string): -1 | 0 | 1
```

**示例 / 验收**：

```text
compareVersion("1.2.10", "1.2.9") → 1；("1.0", "1") → 0
```

<details>
<summary>展开参考答案（TypeScript）</summary>

```ts
function compareVersion(a: string, b: string): -1 | 0 | 1 {
  const x = a.split('.').map(BigInt), y = b.split('.').map(BigInt)
  for (let i = 0; i < Math.max(x.length, y.length); i++) {
    const p = x[i] ?? 0n, q = y[i] ?? 0n
    if (p !== q) return p > q ? 1 : -1
  }
  return 0
}
```

**注意 / 追问**：题设假定各段都是非负整数，不考虑 semver 预发布标记。

</details>

### Q030 · 字符串形式的大整数加法 [P0]

> 归类：**面经直接出现的题型** · [公开来源/参考](https://www.nowcoder.com/discuss/792471798330773504)

**题目（补全版）**：输入非负十进制整数字符串，不能直接转 Number；返回精确和值；考虑进位及不同长度。

```ts
function addStrings(a: string, b: string): string
```

**示例 / 验收**：

```text
addStrings("999", "1") → "1000"
```

<details>
<summary>展开参考答案（TypeScript）</summary>

```ts
function addStrings(a: string, b: string): string {
  let i = a.length - 1, j = b.length - 1, carry = 0, out = ''
  while (i >= 0 || j >= 0 || carry) {
    const sum = (i >= 0 ? +a[i--] : 0) + (j >= 0 ? +b[j--] : 0) + carry
    out = (sum % 10) + out
    carry = Math.floor(sum / 10)
  }
  return out.replace(/^0+(?=\d)/, '') || '0'
}
```

</details>

### Q031 · 括号有效性 [P0]

> 归类：**题库补充 / 高频练习** · [公开来源/参考](https://github.com/yangshun/front-end-interview-handbook)

```ts

```

```text

```

<details>
<summary>展开参考答案（TypeScript）</summary>

```ts
function isValid(s: string): boolean {
  const stack: string[] = [], pair: Record<string,string> = {')':'(',']':'[','}':'{'}
  for (const c of s) {
    if ('([{'.includes(c)) stack.push(c)
    else if (stack.pop() !== pair[c]) return false
  }
  return stack.length === 0
}
```

### Q034 · 用两个栈实现队列 [P1]

```ts
class MyQueue {push(x:number):void; pop():number|undefined}
```

**示例 / 验收**：

```text
push(1),push(2),pop() → 1
```

<details>
<summary>展开参考答案（TypeScript）</summary>

```ts
class MyQueue {
  private inStack: number[] = [], outStack: number[] = []
  push(x: number) { this.inStack.push(x) }
  pop() {
    if (!this.outStack.length) while (this.inStack.length) this.outStack.push(this.inStack.pop()!)
    return this.outStack.pop()
  }
}
```

> 归类：**题库补充 / 高频练习** · [公开来源/参考](https://github.com/yangshun/front-end-interview-handbook)

**题目（补全版）**：给定单链表头结点，原地反转并返回新头结点；O(1) 辅助空间。

```ts
function reverseList(head: ListNode | null): ListNode | null
```

**示例 / 验收**：

```text
1→2→3→null 变为 3→2→1→null
```

<details>
<summary>展开参考答案（TypeScript）</summary>

```ts
type ListNode = { val: number; next: ListNode | null }
function reverseList(head: ListNode | null): ListNode | null {
  let prev: ListNode | null = null, cur = head
  while (cur) {
    const next = cur.next
    cur.next = prev
    prev = cur
    cur = next
  }
  return prev
}
```

</details>

### Q036 · 判断链表是否有环 [P0]

> 归类：**题库补充 / 高频练习** · [公开来源/参考](https://github.com/yangshun/front-end-interview-handbook)

**题目（补全版）**：使用快慢指针判断是否有环；要求 O(1) 额外空间。

```ts
function hasCycle(head: ListNode | null): boolean
```

**示例 / 验收**：

```text
1→2→3→2(环) → true
```

<details>
<summary>展开参考答案（TypeScript）</summary>

```ts
function hasCycle(head: ListNode | null): boolean {
  let slow = head, fast = head
  while (fast?.next) {
    slow = slow!.next
    fast = fast.next.next
    if (slow === fast) return true
  }
  return false
}
```

</details>

### Q041 · 二叉树最近公共祖先 [P1]

> 归类：**题库补充 / 高频练习** · [公开来源/参考](https://github.com/yangshun/front-end-interview-handbook)

**题目（补全版）**：给定普通二叉树及两个存在的节点 p、q，返回最近公共祖先；不依赖 BST 有序性。

```ts
function lowestCommonAncestor(root: TreeNode|null,p:TreeNode,q:TreeNode): TreeNode|null
```

**示例 / 验收**：

```text
p、q 分别位于根的左右子树 → 根
```

<details>
<summary>展开参考答案（TypeScript）</summary>

```ts
function lowestCommonAncestor(root: TreeNode|null,p:TreeNode,q:TreeNode): TreeNode|null {
  if (!root || root === p || root === q) return root
  const left = lowestCommonAncestor(root.left,p,q)
  const right = lowestCommonAncestor(root.right,p,q)
  return left && right ? root : left || right
}
```

</details>

```ts
  nums.sort((a,b)=>a-b)

    if(i>0 && nums[i]===nums[i-1])continue
```

```ts
function mergeSort(nums:number[]):number[] {
```

### Q078 · 实现大文件分块上传调度器 [P1]

> 归类：**面经直接出现的题型** · [公开来源/参考](https://www.nowcoder.com/discuss/800091364976242688)

**题目（补全版）**：将 File 按固定大小切片，最多并发上传 limit 个，全部完成后发送 merge 请求；说明失败重试和断点续传所需的 chunk id。

```ts
async function uploadLargeFile(file:File,chunkSize:number,limit:number):Promise<void>
```

**示例 / 验收**：

```text
10MB 文件，每片 2MB → 5 片，limit=3 时同时最多上传 3 片。
```

<details>
<summary>展开参考答案（TypeScript）</summary>

```ts
async function uploadLargeFile(file:File,chunkSize:number,limit:number){
  const parts:Blob[]=[]
  for(let i=0;i<file.size;i+=chunkSize)parts.push(file.slice(i,i+chunkSize))
  await allLimit(parts.map((blob,index)=>async()=>{
    const body=new FormData()
    body.append('chunk',blob)
    body.append('index',String(index))
    const res=await fetch('/upload/chunk',{method:'POST',body})
    if(!res.ok)throw new Error('chunk '+index)
  }),limit)
  const merge=await fetch('/upload/merge',{method:'POST'})
  if(!merge.ok)throw new Error('merge failed')
}
```

**注意 / 追问**：面试简化版：生产必须增加 fileId/hash、鉴权、会话隔离、幂等、上传进度与重试。

</details>
