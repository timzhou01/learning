请实现一个日期格式化函数，将 `Date` 格式化为 `YYYY-MM-DD`。

示例：
```ts

// '2025-03-08'
```

### 参考答案

> 来源年份：**2022** ｜ 来源：**牛客 · 字节前端日常实习 / 广告业务面经**

#### 参考答案

```ts
function format(d: Date) {
  const y = d.getFullYear()
  const m = String(d.getMonth() + 1).padStart(2, '0')
  const day = String(d.getDate()).padStart(2, '0')
  return `${y}-${m}-${day}`
}
```

```text

```

输出：
```text
3 -> 2 -> 1 -> null
```

### 参考答案

> 来源年份：**2024** ｜ 来源：**牛客 · 抖音电商前端暑期实习面经**

#### 参考答案

```ts
function reverse(head:any){
  let prev=null, cur=head
  while(cur){
    const next=cur.next
    cur.next=prev
    prev=cur
    cur=next
  }
  return prev
}
```

## Q096 · 实现批量并发请求 batchFetch

> 年份：**2025** ｜ 来源：**字节前端基础架构暑期实习一面**


### 题目

请实现 `batchFetch(tasks, limit)`。

- `tasks` 是一组返回 Promise 的函数；
- 同时最多执行 `limit` 个任务；
- 所有任务完成后，按原始顺序返回结果。

示例：
```ts
const result = await batchFetch(tasks, 3)
```

### 参考答案

> 来源年份：**2025** ｜ 来源：**牛客 · 字节前端基础架构暑期实习一面**

#### 参考答案

维护一个 next index 和固定数量 worker：```ts
async function batch<T>(tasks:(()=>Promise<T>)[], limit:number){
  const res:T[] = new Array(tasks.length)
  let next=0
  async function worker(){
    while(true){
      const i=next++
      if(i>=tasks.length) return
      res[i]=await tasks[i]()
    }
  }
  await Promise.all(Array.from({length:Math.min(limit,tasks.length)},worker))
  return res
}
```

手写 debounce。请给出可运行实现，并说明核心思路和时间复杂度。

> 来源年份：**2025** ｜ 来源：**牛客 · 字节跳动-抖音电商（日常）前端面经**

#### 参考答案

```ts
function debounce(fn:Function, delay:number){
  let timer:any
  return function(this:any,...args:any[]){
    clearTimeout(timer)
    timer=setTimeout(()=>fn.apply(this,args),delay)
  }
}
```

## Q105 · 实现一个带超时自动删除的 LRU，怎么设计？

设计并实现一个 LRU Cache，要求：

- `get(key)` / `put(key, value)`；
- 容量超过上限时淘汰最近最少使用的数据；
- 每条数据支持 TTL，过期后视为不存在；

> 来源年份：**2026** ｜ 来源：**牛客 · 字节跳动前端开发实习面经**
